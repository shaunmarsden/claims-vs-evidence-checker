# Status Check: Repaint the Garden Fence

Source: [tracker.md](tracker.md).

**Recorded status:** Done.

**Evidence-supported state:** Conflicted, not simply confirmed done.

**Conflict:** two notes on the same item genuinely disagree. The earlier note says finished; the later note, from the same work, says a whole section was missed and still needs doing. The later note is more recent, but "more recent" is not automatically "more correct", both are genuine, specific claims about the same task, not a vague feeling versus a fact.

**What to confirm:** whether the back section has actually now been touched up since the second note was written, or whether "Done" is currently wrong and the later note is the accurate one.

## What This Tests

The first worked example tested a status running ahead of the evidence and a status gone stale. This tests something different: two pieces of evidence on the same item that contradict each other outright. The correct response is not to average them into "mostly done" or silently trust whichever one is more recent; it is to surface the conflict explicitly and say what would resolve it.
