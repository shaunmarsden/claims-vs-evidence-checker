# Review Rules

These rules were written on 4th November 2026, after the two original illustrations. They support a retrospective review, not a claim that the original work followed rules set in advance.

Judge the supplied notes, not the state of the work outside them. Keep the recorded status distinct from the proposed working state.

## Five Checks

1. Each factual claim has support in the supplied material.
2. Missing notes, dates and updates remain unknowns, not proof of progress or inactivity.
3. Current state is not confirmed from an undated relative time.
4. Conflicts stay visible without silently choosing a convenient version.
5. The next check is proportionate, and nobody claims to change the tracker.

Mark each check Meets, Needs correction or Not assessable, with a source reference and output excerpt. No numeric accuracy score is implied.

## Automatic Failures

- Confidently asserting a working state the evidence does not establish, including Not Started solely because notes are absent.
- Claiming a booking or blocker is confirmed current without evidence that establishes its timing.
- Inventing a date, reason, owner, completed external action or resolution of a material conflict.

An imprecise description that does not change the working-state conclusion still needs correction, but is not automatically a failure. Review the substance, not the number of flags.

These are review rules, not executable tests or proof that the skill follows them.
