# Worked Example Two: Conflicting Evidence

The first [example](../example/) tests a status running ahead of the evidence, and one gone stale. This one tests a harder case: two genuine notes on the same item that contradict each other outright.

- [tracker.md](tracker.md): one item, two notes that disagree
- [output.md](output.md): the status check, which surfaces the conflict rather than averaging it or trusting whichever note is more recent
- [review.md](review.md): whether the conflict actually got named, with a specific way to resolve it
