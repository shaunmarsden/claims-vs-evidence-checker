# Worked Example

A made-up list of four home renovation jobs, checked against the notes held for each.

- [tracker.md](tracker.md): the tracker as given
- [output.md](output.md): an illustration of the status check requested by [SKILL.md](../SKILL.md)
- [review.md](review.md): what the output flagged and where its conclusions still need checking

The output flags the cabinet check and the old tiles entry. Its claims that the electrician booking is current and the hallway work has not started are not established by the notes. Read those limits in the review rather than treating the two items as verified healthy.

The repository doesn't record which model wrote this status check, or whether it knew what the test was checking. Read it as an illustration of what a good run looks like, not as a logged run.
