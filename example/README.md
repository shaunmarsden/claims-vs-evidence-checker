# Worked Example

A made-up list of four home renovation jobs, checked against the notes held for each.

- [tracker.md](tracker.md): the tracker as given
- [output.md](output.md): the status check [SKILL.md](../SKILL.md) produced
- [review.md](review.md): whether it caught the two real mismatches without inventing a problem with the two healthy items, one of which has a label ("Blocked") that might look like a problem in itself

The repository doesn't record which model wrote this status check, or whether it knew what the test was checking. Read it as an illustration of what a good run looks like, not as a logged run.
